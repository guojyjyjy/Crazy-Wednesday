# Brucella-EpiWork 3.3 本地版

## 定位

Brucella-EpiWork 是布病多表位抗原计算筛选与优先级决策平台。系统不手工录入候选蛋白，也不在决策台内维护独立证据库，而是统一使用项目管理、数据中心和证据中心中的已有数据。

## 一键启动（Windows）

1. 完整解压压缩包。

2. 如旧版仍在运行，先双击 `停止项目.bat`。

3. 双击 `一键启动.bat` 或 `启动项目.bat`。

4. 浏览器打开 `http://127.0.0.1:8765`。

5. 登录名：`管理员`，初始密码：`epiwork123`。

`runtime` 已包含 Python 3.14.2，无需额外安装 Python、Node.js 或数据库。

## 标准工作流程

1. 在项目管理中创建项目。

2. 在证据中心登记数据来源和证据线索。

3. 在数据中心导入蛋白 FASTA，并关联来源。

4. 进入抗原决策台，依次选择项目、数据集和序列记录。

5. 系统自动形成“项目 → 数据集 → 记录 → 来源”追溯链，并载入只读序列。

6. 自由选择 4 个本地工具和 3 个外部工具。

7. 运行分析，查看工具状态、候选区域、权重排序和证据线索。

8. 选择候选并导出 CSV、FASTA、JSON 或中文 PDF。

9. 抗原运行结果自动回流证据中心。

10. 可视化中心与报告中心自动读取抗原决策结果。

## 决策台输入边界

* 不提供手工序列输入。

* 不提供 FASTA 上传。

* 不提供示例蛋白。

* 不提供独立的公开证据库管理界面。

* 未选择数据中心记录时，后端拒绝运行。

* 数据集未关联来源时，后端拒绝运行。

## 工具编排

### 本地工具

| 工具             | 方法                    |
| -------------- | --------------------- |
| HP-Window      | Kyte-Doolittle 亲水性滑窗  |
| Flex-Window    | Karplus-Schulz 柔性倾向   |
| Surface-Window | Emini 表面可及性倾向         |
| Turn-Window    | Chou-Fasman beta-转角倾向 |

### 外部工具

| 工具           | 接入方式                                             |
| ------------ | ------------------------------------------------ |
| IEDB-KT      | IEDB Analysis Resource，Kolaskar-Tongaonkar 抗原性预测 |
| BepiPred 2.0 | IEDB Analysis Resource，BepiPred 2.0 线性表位预测       |
| ABCpred      | Raghava ABCpred Web 服务，窗口 16 aa、阈值 0.51          |

7 个工具可以在同一次运行中自由组合。外部服务失败或超时会被标记为降级，不会中断其他工具，也不会用本地结果冒充外部结果。

外部工具需要网络。BepiPred 2.0 单序列最长 250 aa。外部服务最长等待时间可在决策台选择。

## 共识评分

```text
score = 100 × Σ(维度值 × 权重) / Σ权重
```

维度：

* 工具覆盖；

* 证据强度；

* 证据中心线索；

* 跨工具一致性。

权重排序只在点击“保存本次排序”后生成新的排序版本。

## 跨模块关联

| 关联          | 实现                  |
| ----------- | ------------------- |
| 项目 → 决策台    | 项目选择来自项目管理          |
| 数据中心 → 决策台  | 数据集、记录、序列和只读元数据     |
| 证据中心 → 决策台  | 来源下拉、蛋白级/表位级证据线索    |
| 决策台 → 证据中心  | 自动生成“计算结果”证据并关联原始记录 |
| 决策台 → 可视化中心 | 运行、候选、覆盖、分数和来源统计    |
| 决策台 → 报告中心  | 抗原运行、候选、排序版本和证据线索章节 |

## 数据总览

显示候选蛋白、抗原运行、候选区域、证据线索与已选候选，不再以通用任务和评价为中心。

## 可视化中心

主要展示：

* 抗原运行和候选蛋白；

* 候选区域与已选候选；

* 最高共识分；

* 候选分数分布；

* 工具覆盖分布；

* 运行状态；

* 数据来源分布；

* Top 20 候选；

* 项目数据来源链。

## 报告中心

默认中文决策报告包含：

* 项目基本信息；

* 数据集信息；

* 数据来源；

* 抗原运行记录；

* 抗原候选结果；

* 抗原排序版本；

* 抗原证据线索；

* 关联证据；

* 数据质量与异常记录；

* 人工复核；

* 报告历史；

* 局限性声明。

支持 PDF、HTML、JSON 和 CSV。

## AI 决策与评估

菜单位置：报告中心下方、系统审计上方。

AI 页面只评估已经存在的抗原运行，不接收手工序列。评估流程：

1. 读取抗原运行、工具状态、权重、候选分数和项目数据来源链；

2. 读取证据中心中与蛋白或记录相关的证据；

3. 联网检索 UniProt 和 Europe PMC；

4. 将结构化材料发送给 DeepSeek；

5. 返回并归档蛋白可能功能、评分依据、支持要点、不确定性、综合评估、建议验证和引用。

AI 结果只用于解释已有计算证据，不作为新的实验结论。

## API

核心接口前缀：`/api/epitope/`

| 方法   | 路径                                 | 作用               |
| ---- | ---------------------------------- | ---------------- |
| GET  | `/api/epitope/meta`                | 本地与外部工具目录、权重和状态  |
| GET  | `/api/epitope/proteins`            | 已保存蛋白与来源链        |
| POST | `/api/epitope/analyze`             | 运行多工具分析          |
| GET  | `/api/epitope/runs`                | 历史运行             |
| GET  | `/api/epitope/runs/{id}`           | 运行详情             |
| POST | `/api/epitope/runs/{id}/rerank`    | 保存排序版本           |
| POST | `/api/epitope/select`              | 保存候选选择           |
| POST | `/api/epitope/export`              | 导出候选文件           |
| GET  | /api/epitope/visualization/summary | 抗原可视化汇总          |
| GET  | /api/ai/meta                       | DeepSeek 配置与可用状态 |
| POST | /api/ai/evaluate                   | 联网检索并生成 AI 综合评估  |
| GET  | /api/ai/evaluations                | AI 评估历史          |
| GET  | /api/ai/evaluations/{id}           | AI 评估详情          |

`/api/epitope/analyze` 必须携带有效的 `project_id`、`dataset_id`、`record_id` 和 `source_id`。

## 科学边界

* 本地工具是透明启发式基线，不是训练模型复刻。

* 外部结果来自公开服务，受服务版本、队列和网络影响。

* 证据线索主要支持蛋白级或表位级研究判断，不能替代湿实验。

* 共识评分是决策辅助，不构成诊断、疫苗设计或保护性结论。

* 最终候选须经合成、免疫原性、交叉反应及动物/临床实验验证。
